Third-party notices for CorrCUT
==============================

CorrCUT's own code is under the MIT license (see LICENSE next to the
application). The Windows build also includes separate programs and libraries.
Those stay under their own licenses. They are run as separate tools or loaded
as dynamically linked libraries; CorrCUT does not statically link the GPL
tools into its own binary.

Full license texts for the main copyleft and common open-source licenses ship
in the licenses\ folder next to this file (and under
src\corrcut\resources\licenses\ in the source tree).

A BUILD.txt file next to the installed application records the exact download
used for FFmpeg, MKVToolNix, and libmpv when the installer fetched them.

Written offer for corresponding source
--------------------------------------
For any GPL-licensed binary CorrMedia redistributes with CorrCUT (currently
the pinned FFmpeg GPL build, MKVToolNix, and subtile-ocr / vobsubocr), CorrMedia
offers to provide the corresponding source code on a durable physical medium
at cost of distribution, or by download, for three years after you receive
this copy. Request source through the CorrCUT repository that published this
build (the Issues or Discussions page for that release), or use the upstream
URLs listed below and in BUILD.txt. Upstream projects already publish their
source at those URLs; this offer covers redistributed binaries when you prefer
to request them through CorrMedia.

LGPL libraries redistributed with CorrCUT (libmpv, Qt / PySide6, python-mpv
under LGPL, and crc32c) may be replaced in the install tree with a compatible
LGPL build. Source is available at the URLs below; you may also request it
through the same repository Issues or Discussions page.

Not redistributed in the Windows release
----------------------------------------
After pip install, the release script removes packages CorrCUT does not use:

  - language_tool_python (GPL-3.0-only; pulled by sup2srt for optional
    LanguageTool spell-check that this app never calls)
  - PySide6-WebEngine and PySide6-Pdf (and their Qt DLLs), which the editor
    does not import

Those packages are therefore not part of the redistributed application.
